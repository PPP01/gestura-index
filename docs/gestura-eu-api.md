# Vertrag Extension ↔ Index

Der Vertrag liegt **nur im Extension-Repo** und wird von dort direkt gelesen – hier gibt es bewusst keine Kopie, denn ein Abzug daneben driftet:

```text
/mnt/c/Programme.alt/Gestura/docs/gestura-eu-api.md
```

Er hält fest, was ausgelieferte Clients tun; der Dienst richtet sich danach. Wie Änderungen laufen (sichtbar für Clients: erst im Logbuch melden, Antwort abwarten, dann ändern; sonst ändern und danach melden), steht in `CLAUDE.md` und in `docs/extension-austausch.md`. Der Index schreibt den Vertragstext nie selbst.

Frühere Fassung dieser Datei (Kopie, Stand vor dem Verweis): `git log -- docs/gestura-eu-api.md`.
